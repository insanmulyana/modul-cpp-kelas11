Kerangka Utama Program C++ Kelas XI

Setiap program C++ disusun berdasarkan struktur baku yang teratur: modul pustaka, area kerja utama, deklarasi variabel, hingga instruksi keluaran. Pelajari komponennya melalui modul interaktif di bawah ini, atau unduh lembar Panduan PDF dan simpan rekap latihan siswa ke Spreadsheet.

template_kelas11.cpp
C++ Standard
/**
 * Nama Program : Template C++ Kelas XI
 * Deskripsi : Anatomi Lengkap Struktur C++
 */
#include <iostream> [BAGIAN 1: Header Pustaka]
using namespace std; [BAGIAN 2: Namespace Standar]
int main() { [BAGIAN 3: Fungsi Utama]
// [BAGIAN 4: Deklarasi Variabel]
string namaSiswa = "Siswa Hebat";
int tingkatKelas = 11;
double targetNilai = 95.5;
// [BAGIAN 5: Output Tampilan]
cout << "Selamat Datang di Kelas C++!" << endl;
cout << "Nama : " << namaSiswa << endl;
// [BAGIAN 6: Logika Percabangan]
if (targetNilai >= 80) {
    cout << "Status: Sangat Baik!" << endl;
} else {
    cout << "Status: Tingkatkan Belajar!" << endl;
}
// [BAGIAN 7: Penutup Program]
return 0;
}

🔍 Detail Anatomi Kode

Pilih Bagian

Klik salah satu baris kode di editor sebelah kiri untuk membaca penjelasan fungsi, aturan penulisan, serta perannya dalam program C++.

Urutan Eksekusi Komputer:
  1. Membaca Header Pustaka (#include)
  2. Menyiapkan ruang nama (using namespace)
  3. Masuk ke fungsi utama (int main())
  4. Memproses instruksi variabel & logika
  5. Mengakhiri program (return 0)

📊 Ukuran Memori Tipe Data C++

Alokasi memori RAM yang digunakan oleh tiap tipe data standar C++.

🧠 Tipe Data Dasar Kelas XI

int
Integer (Bilangan Bulat)
Menyimpan angka bulat tanpa koma. Contoh: 11, 100, -5.
double
Double / Float (Desimal)
Menyimpan angka pecahan/desimal. Contoh: 95.5, 3.14.
string
String (Teks / Kalimat)
Menyimpan kumpulan karakter. Wajib menggunakan tanda petik dua ("...").
bool
Boolean (Logika)
Hanya bernilai true (1) atau false (0).
